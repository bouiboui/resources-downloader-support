# Resources Downloader support

For product bugs or feature questions, open a
[GitHub support issue](https://github.com/bouiboui/resources-downloader-support/issues/new)
or email [dev@cod3.net](mailto:dev@cod3.net). Support is written and
asynchronous.

Include:

- Chrome or Edge version and operating system;
- Resources Downloader version;
- which action failed: current scan, Reload & rescan, Auto-scroll, Multiple
  pages, Reliable download, normal ZIP, Clean ZIP, or license activation;
- the visible error text and whether retrying helped.

Never include a license key, order details, private page URL, filename list,
downloaded content, or personal data in a public issue. For purchases, refunds,
or private account matters, reply to the private support contact in your Lemon
Squeezy receipt.

Before uninstalling or clearing extension data, use **Deactivate this browser**
in the Pro dialog so the activation becomes available again. If Chrome was
removed, reset, or lost before deactivation, contact private written support
with the order number but not the license key. The publisher can verify the
purchase and release the stale activation in Lemon Squeezy. This recovery is
handled asynchronously and never requires a call.

Before reporting a scan issue, confirm that the page is a normal `http://` or
`https://` page and that Chrome is allowed to download files. Protected Chrome
pages, DRM media, canvas-only images, expired URLs, and access-controlled files
may not be available to an extension.
